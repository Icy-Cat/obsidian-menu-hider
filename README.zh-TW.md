# Menu Hider

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文**

Menu Hider 操作的是選單本身，而不是命令。它讀取你實際開啟的那個右鍵選單裡的項目
—— 包括沒有註冊成命令的項目、以及其他外掛搆不到的選單 —— 因此可以隱藏它們、
調整順序、把它們從子選單裡提出來。

## 功能

- **自動探索** —— 在任意位置右鍵，你開啟的那個選單就會以獨立分頁出現在設定裡，
  項目和圖示一併收集。沒有任何硬編碼，其他外掛新增的選單項同樣能辨識。
- **隱藏項目和分隔線** —— 點選行尾的眼睛圖示。整組被隱藏後，該組連同分隔線一起消失。
- **排序** —— 在同一段（兩條分隔線之間）內拖曳即可重排。
- **提升子選單項目** —— 把子選單裡的項目拖出來，複製到一級選單、緊接在父項目之後；
  拖回去即可還原。
- **複製絕對路徑**（預設關閉）—— 在檔案列表中選取檔案，按 `Ctrl`/`Cmd`+`C`
  即可把它們的絕對路徑複製到剪貼簿。
- 跟隨應用語言，支援 English、简体中文、繁體中文。

## 使用

1. 右鍵點選你想裁剪的對象（檔案、資料夾、標籤頁、編輯器……），這一步會註冊該選單。
2. 開啟**設定 → Menu Hider**，選取對應的選單分頁，點選項目旁的眼睛圖示把它藏起來。
3. 拖曳左側的拖曳把手排序，或把項目拖出子選單以提升它。

重新整理按鈕可以不離開設定頁就重新收集選單；對於無法模擬觸發的選單（多選檔案、URL 選單），
請直接右鍵真實元素。

## 實作方式，以及它的代價

Obsidian 沒有提供讀取或過濾右鍵選單項目的 API，因此本外掛包裝了
`Menu.prototype.showAtPosition` —— 所有 `Menu.show*` 路徑最終都會走到這個方法。
包裝它，外掛才能在選單被測量和繪製之前讀到項目，隱藏才不會閃爍、鍵盤導覽才正確。

需要知道的後果：

- 包裝在外掛載入時安裝、卸載時還原，不會留下永久修改。
- 每次呼叫都包在 `try`/`catch` 裡，外掛內部出錯只會寫入主控台，原方法照常執行。
- `showAtPosition` 不屬於公開 API。如果 Obsidian 改動它，選單仍能正常開啟，
  只是外掛不再裁剪它們。

項目按可見標題比對，所以某個項目改了文案（換語言、外掛升級）後需要重新隱藏一次。

## 與 Commander 的區別

[Commander](https://github.com/phibr0/obsidian-commander) 也能隱藏選單項目。如果你只
需要這個，用它更穩妥 —— 它還順帶做另外十幾件事，而且多數庫裡本來就裝了它。

區別在於各自能「看見」什麼。Commander 比對的是註冊過的命令，且只涵蓋寫死的兩類選單
（`editor-menu` 和 `file-menu`）；不是命令的項目、以及其他所有選單，它搆不到。
Menu Hider 讀的是你實際開啟的那個選單，無論它是什麼。

|              | Commander           | Menu Hider           |
| ------------ | ------------------- | -------------------- |
| 涵蓋選單     | 編輯器 + 檔案，寫死 | 任意選單，右鍵即探索 |
| 設定粒度     | 每類選單一份清單    | 每個選單獨立         |
| 比對方式     | 精確 / 正規表示式   | 精確標題             |
| 重排         | 僅它自己新增的命令  | 任意項目             |
| 提升出子選單 | —                   | 支援                 |
| 原生選單     | 支援                | 僅隱藏可用（見下）   |

## 原生選單

開啟**外觀 → 原生選單**後，右鍵選單由系統繪製，沒有可操作的選單 DOM。隱藏仍然有效
（項目在選單建構前就被剔除），但排序和提升不可用，因為這兩項都依賴算繪出來的選單。
需要它們請關閉原生選單。

## 安裝

**手動安裝** —— 從 [最新 release](https://github.com/Icy-Cat/obsidian-menu-hider/releases/latest)
下載 `main.js`、`manifest.json`、`styles.css` 放進
`<庫>/.obsidian/plugins/menu-hider/`，然後在**設定 → 第三方外掛**中啟用。

## 開發

```bash
npm install
npm run dev     # 監聽建置
npm run build   # 型別檢查 + 生產建置
npm run lint
```

僅支援桌面版：絕對路徑需要本機檔案系統庫。
